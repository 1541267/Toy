동적 배열(Dynamic Array) 시각화

capacity(용량)와 size(개수)를 구분하고, add / remove 시 원소가 어떻게 이동하는지 확인

📖 동적 배열 학습 노트 (클릭해서 펼치기)

🔍 개념

  • 고정 크기 배열의 한계(크기 변경 불가)를 극복하기 위한 자료구조
  • 내부적으론 Object[] 사용, 공간 부족 시 더 큰 배열을 새로 만들어 기존 데이터를 복사
  • capacity(배열의 실제 크기)와 size(실제 요소 개수)를 구분해야 함
  • add(i, e): i번째부터 뒤의 원소들을 오른쪽 끝 인덱스부터 한 칸씩 밀어냄
  • remove(i): i+1번째부터 앞으로 한 칸씩 당겨옴

🔍 Capacity 확장 전략

  • 2배: 확장 횟수가 적어 데이터 복사 비용이 작으나 현재 크기에 비해 여유 메모리가 많이 낭비
  • 1.5배: 2배 확장보다 메모리 여유가 있으나 capacity가 더 빨리 소진되어 확장이 자주 발생되는 만큼 기존 데이터 복사 비용이 증가

✅ 장점

  • 인덱스 접근 O(1)
  • 메모리가 연속적이라 캐시 지역성(Cache Locality)이 좋음

❌ 단점

  • 중간 삽입/삭제 시 나머지 원소를 밀어야 해서 O(n)
  • capacity 초과 시 전체 복사 O(n) 발생
  • 다만 자주 일어나지 않으므로 상각 분석(Amortized)하면 add()는 평균 O(1)

⏱ 복잡도

  • get(i): O(1)
  • add(e) 맨 뒤 추가: O(1) (확장 시에만 O(n))
  • add(i, e) 중간 삽입: O(n)
  • remove(i): O(n)
get O(1) addLast O(1)* addAt O(n) remove O(n)

❓ Object[]를 쓰는 이유

  • 제네릭은 컴파일 시점에만 타입 체크, 바이트코드에선 타입 정보가 지워짐(타입 소거)
  • 런타임엔 E로 배열을 직접 생성할 수 없어 Object[]로 저장 후 꺼낼 때 (E)로 캐스팅
  • 실제 ArrayList<E>도 내부적으로 이 방식을 사용

📄 소스 코드
일반 버전 
// 일반 버전: Object[]를 사용해 동적 배열 구현
static class BasicArray {

  private Object[] arr;
  private int size = 0;

  public BasicArray() {
    this.arr = new Object[10];
  }

  public BasicArray(int capacity) {
    this.arr = new Object[capacity];
  }

  public void add(Object obj) {
    growIfNeeded();
    arr[size++] = obj;
  }

  public void add(int i, Object obj) {
    checkInsertBounds(i);
    growIfNeeded();

    for (int j = size; j > i; j--) {
      arr[j] = arr[j - 1];
    }

    arr[i] = obj;
    size++;
  }

  public Object get(int i) {
    checkElementBounds(i);
    return arr[i];
  }

  public void remove(int i) {
    checkElementBounds(i);

    for (int j = i; j < size - 1; j++) {
      arr[j] = arr[j + 1];
    }

    arr[size - 1] = null;
    size--;
  }

  public int size() {
    return size;
  }

  public int capacity() {
    return arr.length;
  }

  private void growIfNeeded() {
    if (size == arr.length) {
      int newCapacity = (int) (arr.length * 1.5) + 1;
      arr = Arrays.copyOf(arr, newCapacity);
    }
  }

  private void checkInsertBounds(int i) {
    if (i < 0 || i > size) {
      throw new IndexOutOfBoundsException("Index: " + i + ", Size: " + size);
    }
  }

  private void checkElementBounds(int i) {
    if (i < 0 || i >= size) {
      throw new IndexOutOfBoundsException("Index: " + i + ", Size: " + size);
    }
  }
}
제네릭 버전 
// 제네릭 버전: Object[]에 저장하고 get()에서 E로 캐스팅
static class GenericArray<E> {

  private Object[] arr;
  private int size = 0;

  public GenericArray() {
    this.arr = new Object[10];
  }

  public GenericArray(int capacity) {
    this.arr = new Object[capacity];
  }

  public void add(E obj) {
    growIfNeeded();
    arr[size++] = obj;
  }

  public void add(int i, E obj) {
    checkInsertBounds(i);
    growIfNeeded();

    for (int j = size; j > i; j--) {
      arr[j] = arr[j - 1];
    }

    arr[i] = obj;
    size++;
  }

  @SuppressWarnings("unchecked")
  public E get(int i) {
    checkElementBounds(i);
    // Object[]로 저장했으니 꺼낼 때 캐스팅 필요
    return (E) arr[i];
  }

  public void remove(int i) {
    checkElementBounds(i);

    for (int j = i; j < size - 1; j++) {
      arr[j] = arr[j + 1];
    }

    arr[size - 1] = null;
    size--;
  }

  public int size() {
    return size;
  }

  public int capacity() {
    return arr.length;
  }

  private void growIfNeeded() {
    if (size == arr.length) {
      int newCapacity = (int) (arr.length * 1.5) + 1;
      arr = Arrays.copyOf(arr, newCapacity);
    }
  }

  private void checkInsertBounds(int i) {
    if (i < 0 || i > size) {
      throw new IndexOutOfBoundsException("Index: " + i + ", Size: " + size);
    }
  }

  private void checkElementBounds(int i) {
    if (i < 0 || i >= size) {
      throw new IndexOutOfBoundsException("Index: " + i + ", Size: " + size);
    }
  }
}
