힙(Heap)

배열 기반 완전 이진 트리 + insert/remove/search/buildHeap 시각화

📖 힙 학습 노트 (클릭해서 펼치기)

🏔 힙이란

  • 부모-자식 간 순서만 보장하는 완전 이진 트리 (전체 정렬은 보장 안 함)
  • Max-Heap: 부모 ≥ 자식 / Min-Heap: 부모 ≤ 자식, 형제 간 순서는 무관
  • 목적: 특정 값 탐색이 아니라 최댓값/최솟값을 반복적으로 O(log n)에 꺼내는 것

🌳 BST와의 차이

  • BST: 왼쪽 < 노드 < 오른쪽 (전체 순서) -> 탐색 O(log n) 최적화
  • Heap: 부모-자식 순서만 보장 -> 탐색 O(n) (형제 간 순서가 없어 전체를 봐야 함)
  • Heap은 항상 완전 이진 트리라 구조가 절대 불균형해지지 않음 (BST는 편향 가능)

🔢 완전 이진 트리 + 배열 표현

  • 완전 이진 트리(마지막 레벨만 왼쪽부터 채워짐, 빈 구멍 없음) 성질 덕분에 포인터 없이 배열 인덱스 연산만으로 부모-자식 관계 표현 가능
  • parent = (i-1)/2, left = 2i+1, right = 2i+2
  • Node 객체 + 좌우 포인터 불필요 -> 메모리 효율 + 캐시 친화적 (BST와 근본적으로 다른 저장 방식)
⚙️ 핵심 연산

✏️ insert(e) & siftUp

  • 배열 맨 끝에 추가 후, 부모와 비교하며 조건 위반 시 swap 하며 위로 이동
  • 이동 거리 = 트리 높이 이내 -> O(log n)

🗑 remove() & siftDown

  • root 추출 후, 배열 맨 끝 원소를 root 자리로 옮기고 자식과 비교하며 아래로 이동
  • 맨 끝 원소를 옮기는 이유: 중간 원소를 뽑으면 완전 이진 트리에 빈 구멍이 생겨 인덱스 공식이 깨짐
  • 이동 거리도 트리 높이 이내 -> O(log n)

🎯 remove(i) - siftUp/siftDown 중 하나만 필요한 이유

  • 맨 끝 원소를 i 위치로 옮기면, 부모 쪽 위반(siftUp) 또는 자식 쪽 위반(siftDown) 중 하나만 발생 가능, 동시 발생 불가
  • 이유: 옮기기 전 맨 끝 원소는 자기 서브트리 기준 이미 유효했고, i 위치의 원래 값도 자기 부모/자식 관계 기준으론 유효했었기 때문
  • 부모와 딱 한 번 비교해서 방향을 결정하면 충분 (Java PriorityQueue.removeAt()도 동일 기법 사용)
🚀 buildHeap - O(n) 힙 구성

🚀 buildHeap(array)이 O(n)인 이유

  • insert()를 n번 반복하면 O(n log n), 대신 (n/2)-1 (마지막 non-leaf 인덱스)부터 0까지 역순으로 siftDown을 호출하면 O(n)
  • 리프 노드(전체의 약 절반)는 애초에 건드릴 필요 없이 시작 -> 0번 이동
  • 대부분의 노드가 트리 아래쪽(얕은 높이)에 몰려있어, siftDown이 실제로 이동하는 거리가 짧은 노드가 압도적으로 많음
  • 레벨별 (노드 수 × 최대 이동 높이)의 합이 등비급수로 수렴 -> O(n)
  • Heap Sort에서 정렬 안 된 배열을 힙으로 바꾸는 첫 단계가 바로 이 과정

⏱ 힙 연산 복잡도

연산 시간복잡도 비고
peek() O(1) root(배열[0]) 접근
insert(e) O(log n) siftUp, 트리 높이만큼 이동
remove() / remove(i) O(log n) siftDown 또는 siftUp 중 하나
search(e) / remove(e) O(n) 형제 간 순서가 없어 선형 탐색 필요
buildHeap(array) O(n) 리프 비중 + 등비급수 수렴

활용: 우선순위 큐(Java PriorityQueue), Heap Sort, Dijkstra 등 그래프 알고리즘의 "다음 최소 비용 노드" 추출

📄 소스 코드
필드 · 생성자 · buildHeap() 
enum HeapType {MAX, MIN}

private ArrayList<E> arr;
private final HeapType type;

public Heap(HeapType type) {
  if (type == null) {
    throw new IllegalArgumentException("Heap 생성 시 Heap Type 지정 필요");
  }
  this.arr = new ArrayList<>();
  this.type = type;
}

// 배열을 받아 생성과 동시에 O(n) buildHeap 수행
public Heap(ArrayList<E> arr, HeapType type) {
  if (type == null) {
    throw new IllegalArgumentException("Heap 생성 시 Heap Type 지정 필요");
  }
  this.type = type;
  buildHeap(arr);
}

public int getSize() {return arr.size();}

// (n/2)-1 (마지막 non-leaf) 부터 0까지 역순 siftDown -> O(n)
public void buildHeap(ArrayList<E> newArr) {
  // 참조를 그대로 저장하지 않고 방어적 복사(defensive copy)
  // -> 원본 배열과 aliasing 되어 서로 다른 Heap 인스턴스가 오염되는 것 방지
  this.arr = newArr == null ?
      new ArrayList<>() : new ArrayList<>(newArr);

  for (int i = (getSize() / 2) - 1; i >= 0; i--) {
    siftDown(i);
  }
}
insert() & siftUp() 
// heap sort와 다르게 맨 뒤에 삽입 후 부모와 비교하며 힙 구성
public void insert(E e) {
  checkAndThrowAlert(Operation.INSERT, e, 0);

  arr.add(e);

  siftUp(getSize() - 1);
}

// 배열 끝에서 부모와 비교하며 규칙 위반 시 위로 swap 반복
// maxHeap: 자식이 부모보다 작으면 만족 / minHeap: 자식이 부모보다 크면 만족
private void siftUp(int childIdx) {
  while (childIdx > 0) {
    int parentIdx = (childIdx - 1) / 2;

    if (HeapType.MAX.equals(type)) {
      if (arr.get(childIdx).compareTo(arr.get(parentIdx)) <= 0) {break;}
    } else {
      if (arr.get(childIdx).compareTo(arr.get(parentIdx)) >= 0) {break;}
    }

    swap(childIdx, parentIdx);
    childIdx = parentIdx;
  }
}
remove() & siftDown() 
public void remove() {
  checkAndThrowAlert(Operation.REMOVE_ROOT, null, 0);

  if (arr.size() == 1) {
    arr.removeLast();
    return;
  }

  int lastIdx = getSize() - 1;

  arr.set(0, arr.get(lastIdx));
  arr.removeLast();

  siftDown(0);
}

// heapify (sift down), siftUp의 반대 진행
private void siftDown(int i) {
  int parent = i;
  int size = getSize();

  while (true) {
    int left = 2 * parent + 1;
    int right = 2 * parent + 2;

    if (left >= size) {break;}

    int compare = left;

    if (HeapType.MAX.equals(type)) {
      if (right < size && arr.get(right).compareTo(arr.get(compare)) > 0) {
        compare = right;
      }
      if (arr.get(compare).compareTo(arr.get(parent)) <= 0) {break;}
    } else {
      if (right < size && arr.get(right).compareTo(arr.get(compare)) < 0) {
        compare = right;
      }
      if (arr.get(compare).compareTo(arr.get(parent)) >= 0) {break;}
    }

    swap(parent, compare);
    parent = compare;
  }
}
remove(int) · remove(E) · search() · peek() 
// 맨 끝 원소를 i 자리로 이동 -> 부모와 한 번만 비교해서
// siftUp / siftDown 중 하나만 필요 (동시 위반 불가능)
public void remove(int i) {
  checkAndThrowAlert(Operation.REMOVE_IDX, null, i);

  int lastIdx = getSize() - 1;

  if (i == lastIdx) {
    arr.removeLast();
    return;
  }

  arr.set(i, arr.get(lastIdx));
  arr.removeLast();

  if (i == 0) {
    siftDown(i);
    return;
  }

  int parentIdx = (i - 1) / 2;

  if (HeapType.MAX.equals(type)) {
    if (arr.get(i).compareTo(arr.get(parentIdx)) > 0) {
      siftUp(i);
    } else {
      siftDown(i);
    }
  } else {
    if (arr.get(i).compareTo(arr.get(parentIdx)) < 0) {
      siftUp(i);
    } else {
      siftDown(i);
    }
  }
}

// search로 인덱스를 먼저 찾은 뒤 remove(int) 재사용 -> O(n) (search가 지배)
public void remove(E e) {
  checkAndThrowAlert(Operation.REMOVE_VAL, e, 0);
  remove(search(e));
}

// 형제 간 순서가 없어 선형 탐색만 가능 -> O(n)
public int search(E e) {
  checkAndThrowAlert(Operation.SEARCH, e, 0);

  int index = arr.indexOf(e);

  if (index == -1) {
    throw new IllegalArgumentException("찾으려는 데이터가 저장 되어있는 데이터가 아님");
  }

  return index;
}

public E peek() {
  checkAndThrowAlert(Operation.PEEK, null, 0);
  return arr.getFirst();
}
