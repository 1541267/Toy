트라이(Trie)

문자 하나당 노드 하나 + insert/search/startsWith/delete/collect 시각화 (배열 / HashMap / TreeMap)

📖 트라이 학습 노트 (클릭해서 펼치기)

🌲 트라이란

  • 문자열 집합을 문자 하나당 노드 하나로 쪼개 트리 경로로 저장, 공통 접두사는 경로를 공유 (app, apple은 a-p-p 공유)
  • root는 빈 문자열을 뜻하는 빈 노드, root에서 어떤 노드까지의 경로 = 그 노드가 나타내는 접두사
  • isEnd 플래그: 이 노드에서 끝나는 단어가 존재하는지 표시 (app은 저장, ap는 미저장 구분용)
  • 노드가 문자를 들고 있을 필요 없음 (child 인덱스 또는 Map 키가 이미 글자 정보)

❓ 필요한 이유 (길이 L, 개수 N)

구조 정확히 일치 접두사 사전순
HashSet O(L) 불가 불가
TreeMap O(L log N) 범위 탐색 가능
Trie O(L) O(L) 자연스럽게 가능

탐색 비용이 저장 개수 N과 무관하고 검색어 길이 L에만 비례. 대신 노드마다 자식 저장 공간이 필요해 메모리 오버헤드가 큼

⚙️ 핵심 연산

✏️ insert / search / startsWith

  • insert: root부터 글자마다 자식이 없으면 생성하며 내려가고 마지막 노드 isEnd = true -> O(L)
  • findNode: 경로를 따라 내려가 마지막 노드 반환, 중간에 끊기면 null -> O(L)
  • search = node != null && node.isEnd / startsWith = node != null, 차이는 isEnd 검사 한 줄
  • isEnd가 없으면 app만 저장했을 때 search(ap)가 true로 틀림, 경로 확인 없이 isEnd만 보면 NPE
  • root 노드를 두면 첫 글자도 root.child로 똑같이 처리되어 i == 0 분기가 사라짐

🗑 delete 규칙

  • 먼저 존재 확인: 경로가 끝까지 있고 마지막 노드가 isEnd여야 함 (접두사일 뿐이면 false, 변경 없음)
  • 노드를 지워도 되는 조건: 자식이 없고(!hasChild) isEnd도 아님, 두 조건을 동시에 만족
  • 자식이 있음 = 그 경로로 만들어지는 다른 단어가 존재, isEnd를 만남 = 다른 단어의 끝, 둘 다 정리 중단
  • root부터 끝 노드까지 list에 저장 후 역순으로 올라가며 부모가 자식을 끊음 (list.get(i)의 부모는 list.get(i - 1))
  • i >= 1까지 돌면 root가 첫 글자 노드를 끊고 root 자체는 지워지지 않음 -> O(L)

🧺 collectWordsFromPrefix (자동완성 수집)

  • 접두사 노드까지만 내려간 뒤 그 서브트리만 DFS, 다른 가지는 방문하지 않음 (비용은 서브트리 크기에 비례)
  • 재귀 DFS + 백트래킹: StringBuilder append -> 재귀 호출 -> deleteCharAt, StringBuilder는 static 필드가 아니라 재귀 파라미터로 전달
  • 접두사가 없으면 null이 아니라 빈 리스트 반환, 순회 중 put/remove가 없으므로 ConcurrentModificationException 없음
  • 접두사가 a처럼 짧아 서브트리가 거대할 때: 상위 K개만 수집 후 즉시 종료, 노드별 인기도 캐싱, 최소 접두사 길이 제한, 페이지네이션

🧩 자식 저장 방식 비교

기준 배열 Node[26] HashMap TreeMap
자식 조회 O(1) 인덱스 평균 O(1) O(log k), Red-Black Tree
순회 순서 인덱스 순 = 사전순 순서 보장 없음 키 오름차순 = 사전순
허용 문자 고정 (확장 시 배열 급증) 무제한 무제한
메모리 노드마다 26칸 고정, 촘촘할수록 유리 존재하는 자식만 저장, 희소할수록 유리 (엔트리 / 박싱 오버헤드 있음)
hasChild O(26) 순회 isEmpty() O(1) isEmpty() O(1)

HashMap에서 사전순이 필요하면 노드마다 자식 k개 정렬 O(k log k)가 추가됨. 허용 범위가 넓은 이유는 해싱이 아니라 존재하는 자식만 저장하기 때문. 이번 구현 정책: 배열 기반은 소문자 통일 후 a~z만 허용, HashMap/TreeMap 기반은 대소문자 구분, 둘 다 null과 공백 문자열은 예외

⚖️ Trie vs HashSet

  • 접두사 질의, 자동완성, 사전순 순회가 필요하거나 접두사 공유율이 높으면 Trie
  • 단순 존재 확인만 필요하고 접두사를 거의 공유하지 않으면 HashSet이 메모리상 유리
  • 이유는 해싱 비용이 아니라 노드 오버헤드: 공유가 없으면 글자 수만큼 노드를 새로 만들고 노드마다 객체 헤더, 자식 구조, isEnd 비용 발생
  • 노드가 힙에 흩어져 포인터를 따라가야 하므로 캐시 비친화적

🚧 한계와 활용

  • 중간 문자열 검색 불가 (apple에서 pp), 루트에서 시작하는 경로만 따라갈 수 있기 때문
  • 해결: Suffix Trie (공간 O(L^2)) -> Suffix Tree / Suffix Array, 패턴 하나는 KMP, 여러 패턴은 Aho-Corasick
  • 활용: 검색창 자동완성, 오타 교정 후보, IP 라우팅 최장 접두사 매칭, 금칙어 필터, 전화번호 목록 문제
  • 공간복잡도 O(전체 노드 수), 접두사 공유가 많을수록 줄어듦

📄 소스 코드
ArrayBasedBasicTrie (Node[26]) 
static class ArrayBasedBasicTrie {

  static class Node {

    private final char c;
    private Node[] child = new Node[26];
    private boolean isEnd = false;

    public Node(char c) {
      this.c = c;
    }
  }

  private final Node root = new Node('\0');

  public void insert(String word) {
    Node curNode = root;
    int[] idxArr = checkInputAndGetIdxArr(word);

    for (int i = 0; i < word.length(); i++) {
      int idx = idxArr[i];

      if (curNode.child[idx] == null) {
        curNode.child[idx] = new Node(word.toLowerCase().charAt(i));
      }
      curNode = curNode.child[idx];
    }
    curNode.isEnd = true;
  }

  public boolean search(String word) {
    Node node = findNode(word);
    return node != null && node.isEnd;
  }

  public boolean startsWith(String prefix) {
    return findNode(prefix) != null;
  }

  private Node findNode(String word) {
    Node curNode = root;
    int[] idxArr = checkInputAndGetIdxArr(word);

    for (int idx : idxArr) {
      curNode = curNode.child[idx];
      if (curNode == null) {return null;}
    }
    return curNode;
  }

  public ArrayList<String> collectWordsFromPrefix(String prefix) {

    Node start = findNode(prefix);
    ArrayList<String> result = new ArrayList<>();

    if (start == null) {return result;}

    StringBuilder stb = new StringBuilder(prefix);

    collect(start, stb, result);

    return result;
  }

  private void collect(Node node, StringBuilder stb, ArrayList<String> result) {
    if (node.isEnd) {result.add(stb.toString());}

    for (int i = 0; i < 26; i++) {
      if (node.child[i] == null) {continue;}

      stb.append((char) ('a' + i));
      collect(node.child[i], stb, result);
      stb.deleteCharAt(stb.length() - 1);
    }
  }

  public boolean delete(String word) {
    int[] idxArr = checkInputAndGetIdxArr(word);

    Node curNode = root;
    Node prevNode;

    ArrayList<Node> list = new ArrayList<>();
    list.add(root);

    for (int idx : idxArr) {
      curNode = curNode.child[idx];
      if (curNode == null) {
        System.out.println("저장되어 있지 않은 단어를 삭제 시도 word: " + word);
        return false;
      }
      list.add(curNode);
    }

    if (!curNode.isEnd) {
      System.out.println("저장되어 있지 않은 단어를 삭제 시도 word: " + word);
      return false;
    }

    curNode.isEnd = false;

    for (int i = list.size() - 1; i >= 1; i--) {
      curNode = list.get(i);
      prevNode = list.get(i - 1);

      // 지우는 요소의 자식 체크
      // 삭제 도중 다른 단어의 끝에 도달
      // 마지막으로 삭제 요소를 지우면 root만 남는 경우
      if (hasChild(curNode) || curNode.isEnd) {break;}

      prevNode.child[idxArr[i - 1]] = null;
    }

    return true;
  }

  private boolean hasChild(Node curNode) {
    for (Node node : curNode.child) {
      if (node == null) {continue;}
      return true;
    }
    return false;
  }

  private int[] checkInputAndGetIdxArr(String word) {
    if (word == null || word.isBlank()) {throw new IllegalArgumentException("Null or Blink 입력");}

    word = word.toLowerCase();
    int[] idxArr = new int[word.length()];

    for (int i = 0; i < word.length(); i++) {
      char curChar = word.charAt(i);
      if (curChar < 'a' || curChar > 'z') {
        throw new IllegalArgumentException("영어 이외의 잘못된 요소가 입력");
      }

      idxArr[i] = word.charAt(i) - 'a';
    }
    return idxArr;
  }
}
HashMapBasedTrie (HashMap / TreeMap) 
static class HashMapBasedTrie {

  static class Node {

    private final Map<Character, Node> child;
    private boolean isEnd = false;

    public Node(Map<Character, Node> newMap) {
      child = newMap;
    }
  }

  enum Mode {TREE, HASH}

  private final Mode mode;
  private final Node root;

  public HashMapBasedTrie(Mode mode) {
    this.mode = mode;
    root = new Node(createMap());
  }

  private Map<Character, Node> createMap() {
    return mode == Mode.HASH ? new HashMap<>() : new TreeMap<>();
  }

  public void insert(String word) {
    checkInput(word);

    Node curNode = root;
    for (int i = 0; i < word.length(); i++) {

      char curChar = word.charAt(i);

      // 저장된 key 존재 = get(key), key 없을 시 = put
      curNode = curNode.child.computeIfAbsent(curChar, _ -> new Node(createMap()));
    }
    curNode.isEnd = true;
  }

  public boolean search(String word) {
    checkInput(word);
    Node node = findNode(word);
    return node != null && node.isEnd;
  }

  public boolean startsWith(String prefix) {
    checkInput(prefix);
    return findNode(prefix) != null;
  }

  private Node findNode(String word) {

    Node curNode = root;
    for (int i = 0; i < word.length(); i++) {
      char curChar = word.charAt(i);

      Node node = curNode.child.get(curChar);

      if (node == null) {
        return null;
      } else {
        curNode = node;
      }
    }
    return curNode;
  }

  public boolean delete(String word) {
    checkInput(word);

    Node curNode = root;
    Node prevNode;

    ArrayList<Node> list = new ArrayList<>();
    list.add(root);

    for (int i = 0; i < word.length(); i++) {
      char curChar = word.charAt(i);

      Node node = curNode.child.get(curChar);

      if (node == null) {
        System.out.println("저장되어 있지 않은 단어 삭제 시도");
        return false;
      }
      list.add(node);
      curNode = node;
    }

    if (!curNode.isEnd) {
      System.out.println("저장되어 있지 않은 단어 삭제 시도");
      return false;
    }

    curNode.isEnd = false;

    for (int i = list.size() - 1; i >= 1; i--) {
      curNode = list.get(i);
      prevNode = list.get(i - 1);

      if (!curNode.child.isEmpty() || curNode.isEnd) {break;}

      prevNode.child.remove(word.charAt(i - 1));
    }

    return true;
  }

  public ArrayList<String> collectWordsFromPrefix(String prefix) {
    checkInput(prefix);
    ArrayList<String> result = new ArrayList<>();
    Node start = findNode(prefix);

    if (start == null) {return result;}

    StringBuilder stb = new StringBuilder(prefix);

    collect(start, stb, result);

    return result;
  }

  private void collect(Node start, StringBuilder stb, ArrayList<String> result) {
    if (start.isEnd) {result.add(stb.toString());}
    for (Entry<Character, Node> entry : start.child.entrySet()) {

      stb.append(entry.getKey());
      collect(entry.getValue(), stb, result);
      stb.deleteCharAt(stb.length() - 1);
    }
  }

  private void checkInput(String word) {
    if (word == null || word.isBlank()) {
      throw new IllegalArgumentException("입력 단어가 Null or Blink");
    }
  }
}
