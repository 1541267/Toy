Prim 알고리즘 (MST)

정점 중심 그리디 확장 + 우선순위 큐(Lazy Prim) 기반 최소 신장 트리 시각화

📖 Prim 알고리즘 학습 노트 (클릭해서 펼치기)

🌲 Prim 알고리즘이란

  • 정점을 중심으로 트리를 확장하며 MST(최소 신장 트리)를 구성하는 그리디 알고리즘
  • 방문 정점 집합과 미방문 정점 집합을 나눴을 때, 두 집합을 잇는 간선 중 최소 가중치 간선을 매 단계 선택
  • 선택된 간선의 반대쪽 정점을 방문 집합에 편입, 모든 정점이 포함될 때까지 반복
  • 정점 V개짜리 트리는 항상 간선 V-1개로 구성됨

⚖️ Kruskal과의 차이

  • Kruskal: 간선 중심, 전체 간선을 정렬한 뒤 사이클을 만들지 않는 선에서 그리디하게 선택 (Union-Find로 판별)
  • Prim: 정점 중심, 하나의 시작 정점에서 트리를 한 정점씩 확장 (우선순위 큐로 최소 간선 판별)
  • 정당화 논리는 다르지만(Kruskal은 사이클 방지, Prim은 컷 기준 최소 선택) 둘 다 Cut Property에 근거해 정당화됨
  • Cut Property: 임의의 컷을 가로지르는 최소 간선은 반드시 어떤 MST에 포함된다
🐢 Lazy vs Eager Prim

🐢 Lazy Prim (현재 구현)

  • 정점을 방문 처리할 때, 그 정점과 연결된 모든 간선을 조건 없이 우선순위 큐에 추가
  • 큐에서 꺼낼 때(poll) 반대쪽 정점이 이미 방문 상태면 그냥 버림(continue)
  • 같은 목적지를 향한 중복 간선이 큐 안에 여러 개 공존할 수 있음
  • 구현이 단순한 대신, 최악의 경우 큐 크기가 간선 수(E)까지 불어날 수 있음 -> O(E log E)

🐇 Eager Prim (decrease-key, 심화)

  • 정점마다 지금까지 알려진 최소 연결 비용(dist[v])을 관리
  • 더 싼 간선을 발견하면 큐에 새로 넣지 않고, 큐 안의 해당 정점 항목 자체를 갱신(decrease-key)
  • 자바 표준 PriorityQueue는 임의 원소의 우선순위를 낮추는 연산을 지원하지 않아 인덱스 기반 힙을 직접 구현해야 함
  • 큐 크기가 항상 정점 수(V) 이하로 고정 -> O(E log V), E<=V² 이므로 Big-O상 Lazy와 오더는 사실상 동일
  • 실질적 이득은 메모리와 약간의 상수 배수 정도, 그래프가 매우 커야 체감됨

🗺 그래프 표현 - 인접 행렬 vs 인접 리스트

  • 인접 행렬(int[v][v]): 간선 없음은 Integer.MAX_VALUE로 표현, 특정 정점의 인접 간선을 찾으려면 항상 O(V) 순회 필요, 공간 O(V²)
  • 인접 리스트: 특정 정점의 인접 간선만 바로 조회 가능(연결된 만큼만 순회), 무방향 그래프이므로 간선 하나당 양쪽 정점의 리스트에 각각 추가해야 함(한쪽만 넣으면 탐색 누락)
  • Prim은 정점별 인접 간선 조회가 반복되는 알고리즘이라 인접 리스트가 구조적으로 더 잘 맞음
  • 단, 그래프가 조밀함(E ≈ V²에 가까움)인 경우엔 인접 행렬 기반 O(V²)가 Kruskal의 O(E log E)보다 오히려 유리할 수 있음
🛡 방어 로직 & ⏱ 복잡도

🛡 방어 로직

  • 큐가 빈 상태로 루프가 끝났는데 result.size() != v-1 이면 그래프가 연결되어 있지 않다는 의미
  • 이 체크를 하지 않으면, 컴포넌트가 나뉜 그래프에서도 조용히 불완전한 MST가 반환됨 (예외 처리 필요)

⏱ 복잡도 & 활용

방식 시간복잡도 비고
Lazy Prim (인접 리스트 + PQ) O(E log E) 간선을 조건 없이 큐에 추가, 중복 가능
Eager Prim (decrease-key) O(E log V) 인덱스 힙 직접 구현 필요, 큐 크기 <= V
인접 행렬 + 선형 탐색 O(V²) 밀집 그래프에서는 오히려 유리할 수 있음

활용: 그래프가 인접 리스트/행렬 형태로 자연스럽게 주어지는 경우(지도, 네트워크 토폴로지처럼 이 지점에서 어디로 갈 수 있나가 자연스러운 질문인 도메인), 시작점이 고정되어 있고 거기서부터 점진적으로 확장하는 그림이 문제 상황과 잘 맞을 때

공통부분 · Edge 클래스 
static class Edge implements Comparable<Edge> {

  private int from;
  private int to;
  private int weight;

  public Edge(int from, int to, int weight) {
    this.from = from;
    this.to = to;
    this.weight = weight;
  }

  // 가중치 오름차순 비교 -> PriorityQueue가 최소 힙 기준으로 정렬하는 근거
  @Override
  public int compareTo(Edge o) {
    return Integer.compare(this.weight, o.weight);
  }

  @Override
  public String toString() {
    return "\nEdge [from=" + from + ", to=" + to + ", weight=" + weight + "]";
  }
}
인접 리스트 기반 Prim 
private static ArrayList<Edge> doAdjacencyListBasedPrimsAlgorithm(
    ArrayList<ArrayList<Edge>> graph, int start, int v) {
  ArrayList<Edge> result = new ArrayList<>();
  boolean[] visited = new boolean[v];

  PriorityQueue<Edge> queue = new PriorityQueue<>(v);

  visited[start] = true;

  queue.addAll(graph.get(start));

  int totalWeight = 0;

  while (!queue.isEmpty()) {
    Edge curEdge = queue.poll();

    // Lazy Prim 삭제, poll()을 이용한 삭제
    // 큐에 쌓였다가 visited 체크로 버려지는 방식 -> 구현은 단순하나 불필요한 간선까지 큐에 쌓임
    if (visited[curEdge.to]) {continue;}

    visited[curEdge.to] = true;
    queue.addAll(connectedVertexListFromList(graph, visited, curEdge.to));

    totalWeight += curEdge.weight;
    result.add(curEdge);
  }

  if (result.size() != v - 1) {
    throw new IllegalStateException("그래프가 연결되어 있지 않음");
  }

  return result;
}

// 방문하지 않은 인접 정점으로 향하는 간선만 걸러서 반환 -> 연결된 만큼만 순회 (O(degree))
private static ArrayList<Edge> connectedVertexListFromList(
    ArrayList<ArrayList<Edge>> graph, boolean[] visited, int start) {
  ArrayList<Edge> list = new ArrayList<>();

  for (Edge edge : graph.get(start)) {
    if (!visited[edge.to]) {
      list.add(edge);
    }
  }

  return list;
}
인접 행렬 기반 Prim 
private static ArrayList<Edge> doAdjacencyMatrixBasedPrimsAlgorithm(
    int[][] graph, int start, int v) {
  ArrayList<Edge> result = new ArrayList<>();
  boolean[] visited = new boolean[v];

  PriorityQueue<Edge> queue = new PriorityQueue<>(v);

  visited[start] = true;
  queue.addAll(connectedVertexListFromMatrix(graph, visited, start));

  int totalWeight = 0;

  while (!queue.isEmpty()) {
    Edge curEdge = queue.poll();

    if (visited[curEdge.to]) {continue;}

    visited[curEdge.to] = true;

    queue.addAll(connectedVertexListFromMatrix(graph, visited, curEdge.to));
    totalWeight += curEdge.weight;
    result.add(curEdge);
  }

  if (result.size() != v - 1) {
    throw new IllegalStateException("그래프가 연결되어 있지 않음");
  }

  return result;
}

// 간선 없음(MAX_VALUE)이거나 이미 방문한 정점이면 스킵 -> 행(row) 전체를 매번 순회 (O(V))
private static ArrayList<Edge> connectedVertexListFromMatrix(
    int[][] graph, boolean[] visited, int start) {
  ArrayList<Edge> list = new ArrayList<>();

  for (int i = 0; i < graph[start].length; i++) {
    if (graph[start][i] == Integer.MAX_VALUE || visited[i]) {continue;}
    list.add(new Edge(start, i, graph[start][i]));
  }

  return list;
}
