그래프 - 인접 행렬 & 인접 리스트

Adjacency Matrix (boolean 존재 플래그) vs Adjacency List (LinkedHashSet) 동일 연산 비교 시각화

📖 그래프 학습 노트 (클릭해서 펼치기)

🗺️ 그래프란

  • 정점(Vertex)과 간선(Edge)의 집합, 트리보다 더 일반화된 비선형 구조 (사이클 허용, 루트 개념 없음)
  • 간선의 표현 방법이 곧 그래프 구현의 핵심 -> 인접 행렬(2차원 배열) vs 인접 리스트(정점별 이웃 목록)
  • 둘 다 정점 존재 여부와 간선 연결 여부라는 두 가지 책임을 분리해서 관리해야 버그가 줄어듦

🎯 설계 원칙: 상태 분리

  • Circular Queue의 size 필드(꽉 참/빔 구분)와 동일한 원칙이 그래프에도 그대로 적용됨
  • 하나의 상태 변수가 두 가지 의미를 겸하면 결국 어딘가에서 충돌 (self-loop, 가중치 확장 시 특히)
  • 정점 존재 여부 전용 저장소(boolean[] / Set)를 간선 저장소와 완전히 분리하는 것이 표준
🔢 인접 행렬 (Adjacency Matrix)

🔢 정점 존재 플래그 설계 변천

  • 1차 시도: matrix[v][v]를 정점 존재 플래그로 재활용 (별도 공간 절약)
  • 문제점: self-loop을 표현할 공간이 대각선과 충돌, 가중치 그래프 확장 시 존재플래그와 weight가 충돌
  • 개선: boolean[] vertexExists를 별도 분리 -> 정점 존재와 간선 연결의 책임 완전 분리

⚠️ self-loop(자기 참조 간선) 정책

  • 상태 머신, 오토마타, 마르코프 체인 등에서는 필요하지만 일반적인 그래프 문제에서는 불필요
  • 학습 단계에서는 addEdge(u,v)에서 u==v를 예외로 막아 원천 차단
  • 지원 시 추가 고려사항: 자기 자신 포함 여부, degree 계산 +2 처리, BFS/DFS 무한루프 방지(visited)

🗑 removeVertex(vertex) 처리

  • 해당 정점의 행(row)과 열(column) 전체를 0으로 초기화해야 완전히 제거됨
  • 무방향 그래프는 matrix[i][v] == matrix[v][i]로 대칭 -> 한 루프에서 양쪽 동시 처리 가능
  • 비용: O(V) - 정점 수만큼 행/열을 순회

⚖️ 인접 행렬 장단점

  • 장점: 간선 존재 확인 O(1), 구현이 직관적, dense 그래프에서 공간 낭비 적음
  • 단점: 공간복잡도 O(V²) 고정 (실제 간선 수와 무관)
  • 단점: 인접 정점 조회 시 연결 안 된 칸까지 전부 스캔 -> sparse 그래프에서 비효율
📋 인접 리스트 (Adjacency List)

📦 내부 자료구조: LinkedHashSet 선택 이유

  • List(ArrayList 등) 사용 시: addEdge를 중복 호출하면 같은 간선이 여러 번 쌓임 (Matrix는 대입이라 문제 없었지만 List는 add()가 중복 허용)
  • Set으로 전환: 구조적으로 중복 간선을 원천 차단, contains()가 O(1)이라 addEdge/hasEdge 성능도 개선
  • LinkedHashSet: 중복 제거 + 삽입 순서 보존을 동시에 만족 (HashSet은 순서 보장 안 됨)

🕸 dangling reference 방지 (removeVertex)

  • 이 정점 자신의 리스트(adjacencyMap.remove(vertex))만 지우면 안 됨
  • 이 정점을 인접 목록에 들고 있는 다른 모든 이웃 정점들의 리스트에서도 이 정점을 제거해야 함
  • 누락 시 이미 삭제된 정점이 다른 정점의 조회 결과에 계속 남아있는 버그 발생
  • 비용: O(degree) - 연결이 적은 정점을 지울 땐 Matrix보다 빠름

🔗 addEdge/removeEdge 대칭성

  • 무방향 간선 u-v는 u의 리스트에 v 저장 + v의 리스트에 u 저장, 두 곳에 나뉘어 저장됨
  • 한쪽만 갱신하면 hasEdge(u,v)와 hasEdge(v,u) 결과가 어긋나는 버그로 직결됨
⚖️ Matrix vs List 최종 비교

⏱ 연산별 시간복잡도 비교

연산 인접 행렬 인접 리스트 (Set 기반)
공간복잡도 O(V²) 고정 O(V+E) 실제 간선만큼
hasEdge(u,v) O(1) O(1) - Set 선택으로 달성
removeVertex(v) O(V) - 행/열 전체 스캔 O(degree) - 연결된 만큼만
getAdjacentVertices(v) O(V) - 행 전체 스캔 O(degree) - 실제 이웃만
순회 순서 인덱스 오름차순 고정 삽입 순서 그대로 (LinkedHashSet)

실무 기준: 정점 수가 많고 간선이 희소(sparse)한 경우가 대부분이라 인접 리스트가 표준 선택 (SNS, 도로망, 웹 그래프 등). 정점 수가 적고 촘촘한(dense) 그래프에서는 인접 행렬도 여전히 유효.

📄 소스 코드
Adjacency Matrix (boolean 존재 플래그 버전) 
private int[][] matrix;
private boolean[] vertexExists;
private int vertexCount;
private int capacity;

public void addVertex(int vertex) {
  idxCheckWhileVertex(vertex);

  if (vertexExists[vertex]) {
    throw new IllegalStateException("이미 추가 되어있는 Vertex");
  }

  vertexExists[vertex] = true;
  vertexCount++;
}

public void removeVertex(int vertex) {
  idxCheckWhileVertex(vertex);

  if (!vertexExists[vertex]) {
    throw new IllegalStateException("저장되어있는 Vertex가 없음");
  }

  vertexExists[vertex] = false;
  vertexCount--;

  for (int i = 0; i < capacity; i++) {
    matrix[i][vertex] = 0;
    matrix[vertex][i] = 0;
  }
}

public void addEdge(int u, int v) {
  idxCheckWhileEdge(u, v);

  if (matrix[u][v] == 1) {return;}

  matrix[u][v] = 1;
  matrix[v][u] = 1;
}

public void removeEdge(int u, int v) {
  idxCheckWhileEdge(u, v);

  if (matrix[u][v] == 0) {return;}
  matrix[u][v] = 0;
  matrix[v][u] = 0;
}

public boolean hasEdge(int u, int v) {
  idxCheckWhileEdge(u, v);
  return matrix[u][v] == 1;
}

// v 와 인접한 정점들 반환
public ArrayList<Integer> getAdjacentVertices(int v) {
  idxCheckWhileVertex(v);
  ArrayList<Integer> result = new ArrayList<>();

  for (int i = 0; i < capacity; i++) {
    if (matrix[v][i] == 1 && i != v) {
      result.add(i);
    }
  }
  return result;
}

private void idxCheckWhileEdge(int u, int v) {
  if (u == v) {throw new IllegalArgumentException("Self Looping");}
  if (u > capacity - 1 || v > capacity - 1 || u < 0 || v < 0) {
    throw new IndexOutOfBoundsException("IOOB, U: " + u + ", V: " + v);
  }

  if (!vertexExists[u] || !vertexExists[v]) {
    throw new IllegalArgumentException("Vertex가 없는 곳에 Edge 추가 혹은 삭제 시도, U: " + u + ", V: " + v);
  }
}

private void idxCheckWhileVertex(int idx) {
  if (idx > capacity - 1 || idx < 0) {
    throw new IndexOutOfBoundsException("IOOB, idx: " + idx);
  }
}
Adjacency List (LinkedHashSet 기반) 
Map<Integer, LinkedHashSet<Integer>> adjacencyMap;
Set<Integer> vertexFlag = new HashSet<>();
private int vertexCount = 0;

public void addVertex(int vertex) {
  idxCheckWhileVertex(vertex);

  if (vertexFlag.contains(vertex)) {
    throw new IllegalStateException("이미 추가 되어있는 정점");
  }

  vertexFlag.add(vertex);
  adjacencyMap.put(vertex, new LinkedHashSet<>());
  vertexCount++;
}

public void removeVertex(int vertex) {
  idxCheckWhileVertex(vertex);

  if (!vertexFlag.contains(vertex) || adjacencyMap.get(vertex) == null) {
    throw new IllegalStateException("추가 되어있지 않은 정점 삭제 시도");
  }

  for (Integer num : adjacencyMap.get(vertex)) {
    adjacencyMap.get(num).remove(vertex);
  }

  vertexFlag.remove(vertex);
  adjacencyMap.remove(vertex);
  vertexCount--;
}

public void addEdge(int u, int v) {
  idxCheckWhileEdge(u, v);

  LinkedHashSet<Integer> list = adjacencyMap.get(u);
  LinkedHashSet<Integer> list2 = adjacencyMap.get(v);

  if (list.contains(v)) {
    throw new IllegalArgumentException("이미 추가 되어있는 간선 추가 시도");
  }

  list.addLast(v);
  list2.addLast(u);
}

public void removeEdge(int u, int v) {
  idxCheckWhileEdge(u, v);

  LinkedHashSet<Integer> list = adjacencyMap.get(u);
  LinkedHashSet<Integer> list2 = adjacencyMap.get(v);

  if (!list.contains(v)) {
    throw new IllegalArgumentException("추가 되어있지 않은 간선 제거 시도");
  }

  list.remove(v);
  list2.remove(u);
}

public boolean hasEdge(int u, int v) {
  idxCheckWhileEdge(u, v);
  LinkedHashSet<Integer> list = adjacencyMap.get(u);

  return list.contains(v);
}

public ArrayList<Integer> getAdjacentVertices(int vertex) {
  idxCheckWhileVertex(vertex);

  if (!adjacencyMap.containsKey(vertex)) {
    throw new IllegalArgumentException("정점이 존재하지 않는 인덱스 조회");
  }

  return new ArrayList<>(adjacencyMap.get(vertex));
}

private void idxCheckWhileEdge(int u, int v) {
  if (u == v) {throw new IllegalArgumentException("Self Looping");}
  if (u < 0 || v < 0) {
    throw new IndexOutOfBoundsException("IOOB, U: " + u + ", V: " + v);
  }

  if (!vertexFlag.contains(u) || !vertexFlag.contains(v)) {
    throw new IllegalArgumentException("Vertex가 없는 곳에 Edge 추가 혹은 삭제 시도, U: " + u + ", V: " + v);
  }
}

private void idxCheckWhileVertex(int idx) {
  if (idx < 0) {
    throw new IndexOutOfBoundsException("잘못된 Vertex idx: " + idx);
  }
}
