다익스트라 & 벨만-포드 (그래프 최단 경로)

우선순위 큐 기반 다익스트라(지연 삭제 + 경로 복원) / 간선 완화 기반 벨만-포드(음수 사이클 탐지) 시각화

📖 그래프 최단 경로 학습 노트 (클릭해서 펼치기)
🧭 다익스트라 (Dijkstra)

🧭 다익스트라 개요

  • 가중치가 있는 그래프에서 하나의 출발 정점부터 모든 정점까지의 최단 거리를 구하는 알고리즘
  • 조건: 모든 간선의 가중치가 음수가 아니어야 함
  • 지금까지 계산된 거리가 가장 작은 정점을 매번 선택해야 하므로 단순 큐 대신 우선순위 큐(min-heap)가 필요

🆚 BFS와의 차이

  • BFS: 모든 간선을 동일한 무게(1)로 취급 -> 최단 경로 = 간선 개수(hop 수)가 최소인 경로
  • 다익스트라: 간선마다 가중치가 다름 -> 최단 경로 = 거쳐온 가중치의 총합이 최소인 경로
  • 모든 간선의 가중치를 1로 통일한 그래프에 다익스트라를 돌리면 BFS와 결과가 동일해짐 (BFS는 다익스트라의 특수 케이스)
  • 먼저 방문한 순서가 곧 최단 거리라는 BFS의 전제가 가중치 도입 순간 깨짐

🐢 지연 삭제(Lazy Deletion)

  • 표준 PriorityQueue는 이미 들어있는 원소의 우선순위를 직접 수정(decrease-key)하기 어려움
  • 그래서 더 짧은 거리를 찾을 때마다 갱신 대신 새로 push, 큐 안에 낡은 항목이 남을 수 있음
  • poll 시점에 curNode.distance와 dist[]를 비교해서, curNode.distance가 더 크면 이미 더 짧은 경로로 갱신된 낡은 정보이므로 스킵
  • visited[]로 영구 확정하는 최적화가 없는 버전이라, 음수 가중치가 있어도 사이클만 없다면 결과적으로 정답이 나올 수 있음(단, 효율 보장은 깨짐)

🧵 경로 복원 (parent[])

  • dist[]는 거리(숫자)만 저장, 실제로 어떤 정점들을 거쳤는지는 알 수 없음
  • parent[]를 별도로 두고 relax 성공 시 parent[도착점] = 출발점으로 갱신
  • 목적지에서부터 시작해서 parent를 따라 -1이 나올 때까지 역추적, 모은 뒤 reverse하면 시작점 -> 목적지 순서의 실제 경로가 됨

⚡ 그리디로 동작하는 이유

  • 음수 가중치가 없다는 전제 덕분에, 한 번 poll(확정)된 정점의 거리는 이후 더 짧은 경로로 다시 갱신될 수 없음
  • 그래서 큐에서 꺼낸 순간 바로 그 정점의 최단 거리를 확정 지어도 안전함

⏱ 다익스트라 시간복잡도

구현 방식 시간복잡도 비고
인접리스트 + 우선순위 큐(이진 힙) O((V + E) log V) 가장 일반적인 구현
인접행렬 + 배열 선형 탐색 O(V^2) 이웃 확인 자체가 이미 O(V)라 힙 사용 이득 없음

decrease-key를 O(log n)에 하려면 정점과 힙 배열 인덱스를 매핑하는 별도 구조(Indexed Priority Queue)가 필요, 이 구현은 그 대신 지연 삭제 방식을 사용

➕➖ 벨만-포드 (Bellman-Ford)

➕➖ 벨만-포드 개요

  • 다익스트라와 동일하게 출발 정점부터 모든 정점까지의 거리를 구하지만 음수 가중치 간선이 있어도 동작함
  • 조건: 음수 사이클은 없어야 함
  • 우선순위 큐로 순서를 고르는 대신, 그래프의 모든 간선을 V-1번 반복해서 무차별적으로 relax

🔁 V-1번 반복하는 이유

  • 정점이 V개면 사이클 없는 최단 경로가 거칠 수 있는 간선의 최대 개수는 V-1개
  • 한 번의 전체 패스(모든 간선 순회)마다 최소 하나의 새로운 hop이 확정된다고 보장할 수 있으므로 V-1번 반복하면 모든 최단 경로가 수렴
  • 한 패스 전체를 다 돈 뒤에도 갱신이 하나도 없었다면 이미 수렴 완료 -> 조기 종료 가능(단, 이 체크는 반드시 패스 전체가 끝난 뒤 딱 한 번만)

🚨 음수 사이클 탐지 원리

  • V-1번으로 이미 모든 최단 경로가 수렴했어야 정상
  • V번째 패스에서도 여전히 더 짧아지는 간선이 있다면, 사이클을 돌 때마다 거리가 계속 줄어드는 경로가 있다는 뜻 -> 음수 사이클 존재
  • 다익스트라는 애초에 음수 가중치를 전제하지 않으므로 이 탐지 자체가 불가능

⚖️ 다익스트라 vs 벨만-포드

비교 항목 다익스트라 벨만-포드
음수 가중치 불가(오답 위험) 가능
음수 사이클 탐지 불가 가능(고유 기능)
자료구조 우선순위 큐 필수 단순 반복문만으로 충분
매 반복의 순회 대상 poll된 정점의 인접 정점만 매 패스마다 모든 간선
시간복잡도 O((V+E) log V) O(V x E)
접근 방식 그리디(한 번 확정하면 안 바뀜) 반복적으로 계속 완화

다익스트라는 똑똑하게 순서를 골라 한 번씩만 확정하는 방식, 벨만-포드는 순서 상관없이 여러 번 반복해서 수렴시키는 방식 - 그 무차별함 덕분에 음수 가중치도 버티고 사이클 존재 여부까지 검증 가능

📄 소스 코드
공통 부분 - Edge, createGraph 
static class Edge {

  private int from;
  private int dest;
  private int weight;

  public Edge(int from, int dest, int weight) {
    this.from = from;
    this.dest = dest;
    this.weight = weight;
  }
}

// 정점 개수만큼 빈 인접 리스트를 미리 만들어 둠
static List<List<Edge>> createGraph(int v) {
  List<List<Edge>> graph = new ArrayList<>();

  for (int i = 0; i < v; i++) {
    graph.add(new ArrayList<>());
  }

  return graph;
}
다익스트라 - NodeDistance + dijkstra + 경로 복원 
static class NodeDistance implements Comparable<NodeDistance> {

  private int vertex;
  private int distance;

  public NodeDistance(int vertex, int distance) {
    this.vertex = vertex;
    this.distance = distance;
  }

  public int compareTo(NodeDistance o) {
    return Integer.compare(this.distance, o.distance);
  }
}

// 거리 배열만 반환하는 기본 버전
private static int[] dijkstra(List<List<Edge>> graph, int start, int v) {

  int[] dist = new int[v];
  Arrays.fill(dist, Integer.MAX_VALUE);

  dist[start] = 0;

  PriorityQueue<NodeDistance> queue = new PriorityQueue<>();
  queue.add(new NodeDistance(start, 0));

  while (!queue.isEmpty()) {
    NodeDistance curNode = queue.poll();

    // 지연 삭제: 이미 더 짧은 경로로 갱신된 낡은 항목이면 스킵
    if (curNode.distance > dist[curNode.vertex]) {continue;}

    for (Edge edge : graph.get(curNode.vertex)) {
      int newDist = curNode.distance + edge.weight;

      if (newDist < dist[edge.dest]) {
        dist[edge.dest] = newDist;
        queue.add(new NodeDistance(edge.dest, newDist));
      }
    }
  }

  return dist;
}

// parent[]로 실제 경로까지 복원하는 버전
private static ArrayList<Integer> pathRecordDijkstra(List<List<Edge>> graph, int start, int target, int v) {

  int[] dist = new int[v];
  Arrays.fill(dist, Integer.MAX_VALUE);
  dist[start] = 0;

  int[] parent = new int[v];
  Arrays.fill(parent, -1);

  PriorityQueue<NodeDistance> queue = new PriorityQueue<>();
  queue.add(new NodeDistance(start, 0));

  while (!queue.isEmpty()) {
    NodeDistance curNode = queue.poll();
    if (curNode.distance > dist[curNode.vertex]) {continue;}

    for (Edge edge : graph.get(curNode.vertex)) {
      int newDist = curNode.distance + edge.weight;

      if (newDist < dist[edge.dest]) {
        dist[edge.dest] = newDist;
        queue.add(new NodeDistance(edge.dest, newDist));
        parent[edge.dest] = curNode.vertex;
      }
    }
  }

  ArrayList<Integer> path = new ArrayList<>();
  int cur = target;

  while (cur != -1) {
    path.add(cur);
    cur = parent[cur];
  }

  Collections.reverse(path);
  return path;
}
벨만-포드 - V-1번 완화 + 음수 사이클 탐지 
private static int[] bellmanFord(List<List<Edge>> graph, int start, int v) {
  int[] distance = new int[v];
  Arrays.fill(distance, Integer.MAX_VALUE);
  distance[start] = 0;

  // v - 1번 완화
  for (int i = 0; i < v - 1; i++) {

    boolean updated = false;

    for (List<Edge> edges : graph) {
      for (Edge edge : edges) {

        int curVertex = edge.from;
        int nextVertex = edge.dest;

        if (distance[curVertex] != Integer.MAX_VALUE
            && distance[nextVertex] > distance[curVertex] + edge.weight) {
          distance[nextVertex] = distance[curVertex] + edge.weight;
          updated = true;
        }
      }
    }

    // 이번 반복에서 아무것도 갱신되지 않았다면 이미 수렴 완료
    if (!updated) {break;}
  }

  // V번째 패스: 그래도 갱신이 일어나면 음수 사이클 존재
  for (List<Edge> edges : graph) {
    for (Edge edge : edges) {
      int curVertex = edge.from;
      int nextVertex = edge.dest;

      if (distance[curVertex] != Integer.MAX_VALUE
          && distance[nextVertex] > distance[curVertex] + edge.weight) {
        throw new IllegalStateException("음수 사이클이 존재");
      }
    }
  }

  return distance;
}
