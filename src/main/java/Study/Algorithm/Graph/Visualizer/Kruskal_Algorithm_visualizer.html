크루스칼(Kruskal) MST

간선 중심 Greedy + Union-Find 기반 최소 신장 트리 시각화

📖 Kruskal MST 학습 노트 (클릭해서 펼치기)

🌲 신장 트리 & MST

  • 신장 트리: 모든 정점을 포함하면서 사이클이 없는 부분 그래프, 정점이 V개면 간선은 항상 V-1개
  • MST: 신장 트리 중 간선 가중치 합이 최소인 트리
  • 가중치 있는 무방향 연결 그래프에서 정의, 비연결 그래프면 최소 신장 숲(forest)이 나옴

⚙️ Kruskal 개요 (간선 중심 Greedy)

  • 모든 간선을 가중치 오름차순 정렬
  • 간선을 하나씩 꺼내 양 끝 정점이 이미 같은 집합인지 확인
  • 다른 집합이면 채택 & union, 같은 집합이면 사이클이라 버림
  • 채택한 간선이 V-1개가 되면 조기 종료

🔗 Union-Find와의 관계

  • 선택된 간선들만으로 두 정점의 연결 여부를 DFS/BFS로 매번 확인하면 최악의 경우 간선마다 O(V+E)
  • Union-Find(경로 압축 + union by size)를 쓰면 이 판단이 사실상 O(1)에 가까움(O(α(n)))
  • 결과적으로 알고리즘의 병목이 간선 정렬(O(E log E))로 이동
  • union()이 성공 여부(boolean)를 리턴하도록 하면, 같은 집합인지 확인 + union 실행을 한 번의 호출로 처리 가능 -> findRoot를 이중으로 호출하는 비효율 제거

⏱ 시간복잡도

  • 전체: O(E log E), E ≤ V^2 이므로 O(E log V)와 사실상 동일
  • Prim(우선순위 큐 기반, O(E log V))과 점근적으로 유사하나, 간선이 적은 sparse 그래프에서 특히 유리

🧩 비연결 그래프 처리

  • 모든 간선을 다 순회해도 채택된 간선이 V-1개 미만이면 비연결 그래프
  • 정점 0~V-1을 순회하며 findRoot() 결과의 distinct 개수를 세면 연결 요소 개수를 알 수 있음
  • 이 경우 결과는 MST가 아니라 최소 신장 숲, 연결 요소 개수만큼 트리로 나뉨
✂️ Cut Property - Greedy가 최적해를 보장하는 이유

✂️ Cut Property

  • Cut: 전체 정점을 논리적으로 두 그룹 A, B로 나누는 것, 실제 그래프를 바꾸는 게 아니라 간선의 안전성을 설명하기 위한 개념
  • Crossing Edge: A와 B를 연결하는 간선
  • Cut Property: 어떤 cut이 주어졌을 때, 그 cut을 가로지르는 간선 중 가중치가 가장 작은 간선을 포함하는 MST가 항상 존재함 -> 그 간선을 선택해도 전체 최적성을 잃지 않음
  • Kruskal에서 현재까지 선택된 간선들이 만드는 하나의 연결 요소를 A, 나머지 정점을 B로 보면 하나의 cut이 만들어지고, 서로 다른 요소를 잇는 간선이 그 cut의 Crossing Edge가 됨
  • 가중치 오름차순으로 확인하므로 항상 그 cut에서 가장 가벼운 Crossing Edge를 선택하게 되고, Cut Property에 의해 이 선택은 안전함
  • 동일 가중치 간선이 여러 개면 MST가 여러 개 존재할 수 있음: 총 가중치 합은 항상 유일하지만, 그 합을 만드는 구체적인 간선 조합은 정렬 안정성이나 tie-break 기준에 따라 달라질 수 있음

📉 path compression / union by size가 없다면

  • 매번 한쪽을 다른 쪽 밑에 무조건 붙이기만 하면 트리가 한쪽으로 계속 길어지는 편향 구조가 될 수 있음
  • 이 경우 정점 개수만큼 깊이가 길어진 연결리스트와 다를 바 없는 최악의 형태가 되어, findRoot가 매번 O(n)까지 나빠질 수 있음
  • union by size(또는 rank)는 낮은 트리를 높은 트리 밑에 붙여서 이런 편향을 막고, path compression은 한 번 찾은 경로를 눌러서 이후 조회를 더 빠르게 만듦

⏱ 연산 복잡도

연산 시간복잡도 비고
간선 정렬 O(E log E) 알고리즘의 병목 구간
findRoot(경로 압축) O(α(n)) 사실상 상수에 가까움
union(size 기준) O(α(n)) findRoot 2회 + 트리 결합
전체 Kruskal O(E log E) E ≤ V^2 이므로 O(E log V)와 동일

비교: Prim은 우선순위 큐로 정점을 확장(O(E log V)), Kruskal은 간선을 정렬해 전역적으로 가장 가벼운 것부터 채택

Edge 클래스 
static class Edge {

  private final int from;
  private final int to;
  private final int weight;

  public Edge(int from, int to, int weight) {
    this.from = from;
    this.to = to;
    this.weight = weight;
  }

  @Override
  public String toString() {
    return "Edge [from=" + from + ", to=" + to + ", weight=" + weight + "]\n";
  }
}
UnionFind 클래스 
static class UnionFind {

  private int[] parent;
  private int[] size;
  private int connectedComponentCount;

  public UnionFind(int n) {
    if (n < 1) {
      throw new IllegalArgumentException("배열 초기화 크기가 너무 작음, idx: " + n);
    }

    this.parent = new int[n];
    this.size = new int[n];
    connectedComponentCount = n;
    for (int i = 0; i < n; i++) {
      parent[i] = i;
      size[i] = 1;
    }
  }

  public int findRoot(int idx) {
    if (idx < 0 || idx >= parent.length) {
      throw new IndexOutOfBoundsException("잘못 된 인덱스, idx: " + idx);
    }

    int root = idx;

    // find root
    while (root != parent[root]) {
      root = parent[root];
    }

    int cur = idx;

    // path compression
    while (cur != parent[cur]) {
      parent[cur] = root;
      cur = parent[cur];
    }

    return root;
  }

  public boolean union(int x, int y) {
    int rootX = findRoot(x);
    int rootY = findRoot(y);

    if (rootX == rootY) {return false;}

    if (size[rootX] < size[rootY]) {
      size[rootY] += size[rootX];
      parent[rootX] = rootY;
    } else {
      size[rootX] += size[rootY];
      parent[rootY] = rootX;
    }

    connectedComponentCount--;
    return true;
  }

  public boolean isConnected(int x, int y) {
    return findRoot(x) == findRoot(y);
  }

  public int getConnectedComponentCount() {
    return connectedComponentCount;
  }
}
🧰 헬퍼 메서드
간선 정렬 & Kruskal 메인 로직 
// 간선 가중치 오름차 정렬
private static List<Edge> createEdgeListAndSortByWeightOrder(int[][] edges) {
  List<Edge> edgesList = new ArrayList<>();

  for (int[] arr : edges) {
    edgesList.add(new Edge(arr[0], arr[1], arr[2]));
  }

  edgesList.sort(Comparator.comparingInt(e -> e.weight));

  return edgesList;
}

// 간선을 하나씩 확인하며 사이클이 아니면 채택 & union, V-1개 채택 시 조기 종료
private static void DoKruskalMST(List<Edge> edges, UnionFind uf, List<Edge> result, int v) {
  for (Edge edge : edges) {
    if (uf.union(edge.from, edge.to)) {
      result.add(edge);
      if (result.size() == v - 1) {break;}
    }
  }
}
연결 요소 개수 파악 
// 모든 정점을 조사해 findRoot()의 distinct 개수를 세면
// 연결 요소(Connected Component) 개수를 알 수 있음 -> O(V)
// (또는 union() 성공 시마다 connectedComponentCount--로 O(1) 조회도 가능)
private static void findAndPrintConnectedComponents(UnionFind uf, int v) {
  Set<Integer> roots = new HashSet<>();

  for (int i = 0; i < v; i++) {
    roots.add(uf.findRoot(i));
  }

  // roots.size() == 1 -> 그래프가 모두 연결됨(MST)
  // roots.size() > 1 -> 최소 신장 숲(Minimum Spanning Forest)
  System.out.println("Distinct Roots 개수: " + roots.size() + ", 연결 요소들: " + roots);
  // UnionFind의 ComponentCount 상태
  System.out.println("ConnectedComponentCount: " + uf.connectedComponentCount);
}
